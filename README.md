# Thực hành Web BIE5030

Hệ thống thực hành học phần **Phát triển web kinh doanh (BIE5030)**, Bộ môn Thương mại điện tử, Khoa Hệ thống thông tin, Trường Đại học Kinh tế - Luật, ĐHQG-HCM.

- **Bài giảng** (`bai-giang.html`): nội dung lý thuyết, ví dụ, câu hỏi luyện tập.
- **Thực hành** (`index.html`): 16 bài học, 20 bài tập HTML, CSS, JavaScript, DOM chấm tự động; xuất file bài nộp (.html) có mã xác thực để nộp trên LMS.

Trang tĩnh, không cần máy chủ: tiến độ lưu trên trình duyệt của người học, không gửi dữ liệu đi đâu.

Biên soạn: ThS. Phạm Lê Quang.
